# PADEL ESCAPE — первая рабочая версия

Для Егора. Дата сборки: 13 ноября 2026.

Это исходный код и пакет запуска Telegram-бота по согласованному ТЗ.
Бот ещё не подключён к настоящему Telegram-аккаунту и не запущен на сервере.
Автоматические проверки используют тестовую базу и имитацию Telegram API.

## Что реализовано

- Постоянная база SQLite; одноразовая регистрация в личке.
- Полное имя необязательно; уровень обязателен, дальнейшие изменения только администрацией.
- Username необязателен; профиль связан с Telegram ID.
- Пошаговая админка: фото, корт, формат, дата/время, длительность, лимит, карта/pin, стоимость, валюта, включённое, уровни, закрытие записи.
- Предпросмотр, публикация, редактирование, копирование без состава/оплат, отмена, закрытие, завершение.
- Кнопки «Иду / Не иду / Очередь»; подтверждение отказа от занятого места.
- Ограничение вместимости с транзакционной защитой последнего места.
- Разделение готовых и неуверенных; предложения места с резервом и сроком подтверждения.
- Срок предложения по умолчанию 30 минут, изменяется администратором.
- Очередь готовых — по времени готовности. Просроченное предложение переводит игрока в неуверенные.
- Личные напоминания за 24, 12, 2 и 1 час; очередь уведомлений сохраняется в базе.
- Уведомления об изменениях и отмене; старые напоминания отменяются.
- Только для администрации: оплаты, исторические суммы, сводка, оплаты отменившихся.
- Ручное управление участниками и уровнями, личные рассылки с предпросмотром, закрепление.
- Разделы ближайших турниров, моих регистраций, моей очереди, участников и задач.
- Автозапуск systemd, корректная остановка, локальные резервные копии за 7 дней.

## Особенности первой версии

1. Фото публикуется первым отдельным сообщением, следом — обновляемая текстовая карточка с кнопками.
   Так длинные данные не обрезаются ограничением подписи к фото.
2. В группе видны счётчики и списки игроков в пределах размера сообщения Telegram.
   Длинные полные имена в сводке сокращаются до 30 символов. Полные списки доступны всем через
   кнопку в личке, с пагинацией по 15 строк. При длинных списках карточка показывает указание на кнопку.
3. Нажатие групповой кнопки открывает личный чат: действие выполняется после Start.
   Это обеспечивает регистрацию и доступность личных напоминаний.
4. Администраторы указываются числовыми Telegram ID в настройках. Администратор группы
   не получает доступ к оплатам автоматически.
5. Первоначальный список уровней: D, D+, C-, C, C+, B-, B, B+, A.
   Это настраиваемая шкала сообщества; точный перечень нужно подтвердить Егору до приглашения игроков.
6. Обновление ника происходит при следующем взаимодействии участника с ботом.
7. Онлайн-оплата, разбивка по парам/кортам, результаты матчей и подсчёт рейтинга не входят в этот релиз.
8. Одна группа на одну базу. После публикации карточек смена группы блокируется, чтобы не смешивать идентификаторы сообщений.

## Быстрая настройка — после получения сервера

Рекомендуемая ОС для комплектного установщика: Ubuntu 24.04 с Python 3.12 и systemd.
Приложение требует Python 3.11+ и базу часовых поясов ОС. Внешних Python-библиотек нет.
Токен не присылать в чат и не помещать в публичный репозиторий.

1. Распаковать архив на сервер и открыть папку padel_escape.
2. Убедиться, что прежний экземпляр программы не запущен. Не подключать этот же токен к другому конструктору.
3. Выполнить:

   python3 configure.py

   Ввести токен BotFather в скрытое поле терминала.
   Отправить боту личную команду с одноразовым кодом, указанную настройщиком.
   Проверить имя и ID найденного владельца, подтвердить словом YES в терминале.
   Создастся закрытый файл .env.
   Настройщик не удаляет существующий webhook и не меняет настройки работающего стороннего сервиса.
4. Проверить локальные настройки:

   python3 bot.py --check

5. Проверить программу:

   python3 -m unittest discover -s tests -v

6. Для краткого ручного теста:

   python3 bot.py

   Остановка — Ctrl+C. Не закрывать терминал, рассчитывая, что ручной запуск останется активным.
7. Для постоянного запуска:

   sudo bash deploy/install.sh

   Скрипт создаёт системного пользователя padelbot, сохраняет программу в /opt/padel-escape,
   устанавливает службу и включает автоматический запуск после перезагрузки.
   Существующие .env и база при повторном запуске не перезаписываются.
   На этапе первой установки data должна оставаться пустой: установщик не переносит базу ручного теста.
   Для переноса существующей базы остановить оба процесса и отдельно перенести её согласованную копию.

## Проверка в Telegram

1. Создать отдельную тестовую группу.
2. Добавить бота администратором с правом отправки сообщений, фото и закрепления.
3. С аккаунта владельца отправить /bind в этой группе.
4. В личке бота отправить /start, зарегистрироваться, затем /admin.
5. В админке нажать «Закреп регистрации».
6. Создать турнир: загрузить фото, пройти 12 шагов, посмотреть предпросмотр, опубликовать.
7. Вторым обычным аккаунтом пройти регистрацию и записаться; убедиться, что оплат не видно.
8. Проверить отказ, очередь, предложение места и смену статусов; для быстрой проверки поставить срок предложения 1 мин.
9. В админке отметить оплату, затем отменить участие: финансовая запись должна сохраниться.
10. Изменить время/корт: проверить личные уведомления и обновление карточки.
11. Проверить закрепление и рассылку только тестовым пользователям.
12. Проверить перезапуск службы: профили, записи и оплаты должны сохраниться.

Перед основной группой тест должен пройти целиком.
Если публикации уже были в тестовой группе, для запуска в основной группе использовать
новую чистую production-базу (сохранив тестовую отдельно), не менять ID группы в существующей базе.

## Настройки

BOT_TOKEN — ключ BotFather.
OWNER_ID — числовой Telegram ID владельца.
ADMIN_IDS — доверенные администраторы через запятую.
GROUP_ID — можно оставить пустым и выполнить /bind владельцем в группе.
DB_PATH — data/padel.sqlite3.
LEVELS — перечень уровней через запятую; индекс кнопок зависит от порядка.
Изменение LEVELS после регистрации игроков требует согласованного обновления старых профилей.
Для изменения файловой конфигурации перезапустить службу.

## Команды обслуживания

Проверка:
sudo systemctl status padel-escape --no-pager

Логи:
sudo journalctl -u padel-escape -n 100 --no-pager

Перезапуск:
sudo systemctl restart padel-escape

Остановка:
sudo systemctl stop padel-escape

Проверка памяти процесса:
sudo systemctl show padel-escape -p MemoryCurrent -p MemoryPeak

Не передавать содержимое .env и базу игроков в общедоступные чаты.

## Резервные копии и восстановление

Ежедневно при работающем процессе создаётся согласованная копия базы в data/backups.
Хранятся последние 7 дневных копий. Копии на том же сервере не защищают от потери сервера.
Нужно отдельно настроить копирование в другое приватное хранилище.

Ручная согласованная копия:
python3 backup.py /opt/padel-escape/data/padel.sqlite3 /путь/к/новой-копии.sqlite3

Восстановление: остановить службу, сохранить нынешний каталог data отдельно, заменить основную базу
резервной копией, удалить только старые сопутствующие файлы этой базы -wal и -shm после остановки
и сохранения каталога, выставить владельца padelbot и права 0600, запустить службу.
Не копировать только основной sqlite-файл у работающего процесса: использовать backup.py.

## Известные ограничения и честные гарантии

- Реальное соединение с Telegram, права в группе и длительная работа на VPS пока не проверены.
- 512 МБ — целевой размер памяти сервера, а не подтверждённый нагрузочным тестом production-лимит.
- Напоминания не приходят до запуска бота игроком или при блокировке бота.
  Ошибки доставки видны администрации. Просроченные напоминания старше 15 минут пропускаются.
- Уведомления сохраняются и повторяются после временных ошибок. При редком обрыве сразу после
  принятия сообщения Telegram, но до записи результата в SQLite возможно повторное сообщение:
  Telegram sendMessage не предоставляет ключа идемпотентности.
- Авария в момент первой публикации до сохранения message_id также может привести к дубликату карточки.
- Деньги хранятся целыми минимальными единицами (2 знака после запятой), без ошибок float.
  Изменение цены не меняет историческую сумму оплаты. Валюту при сохранённых оплатах менять нельзя.
- Закрытие записи снимает неподтверждённые резервы, оставляя игроков в очереди.
- При ошибке доставки предложения место сохраняется до истечения срока; администратор видит ошибку.
- Нет встроенного веб-сайта или внешней админки; управление — внутри Telegram.
