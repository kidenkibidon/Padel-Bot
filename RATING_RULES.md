# Внутренний рейтинг PADEL ESCAPE

Это собственная система сообщества, а не официальная шкала навыка.
Буквенный уровень D, D+, C-, C, C+, B-, B, B+ остаётся отдельным полем.

## Правила

- Каждый игрок начинает с 2.00.
- Срока действия, сезонного обнуления и списаний за неактивность нет.
- Учитываются только подтверждённые администратором итоговые места завершённых турниров.
- Отдельных очков за участие нет. Турнир без итоговых мест не меняет рейтинг.
- Первые три турнира помечаются как предварительные; формула при этом та же.
- Один турнир меняет рейтинг не более чем на 0.20 в любую сторону. Нижняя граница — 0.
- Все соперники сравниваются по рейтингу ДО начала расчёта данного турнира.
- Число соперников не умножает награду: результат усредняется по составу.
- Одинаковые места считаются ничьей при сравнении игроков.
- Нулевой или единственный участник не создаёт соревновательный результат.

## Формула

Для игрока i против каждого другого участника j:

    ожидаемый результат Eij = 1 / (1 + 10^(Rj - Ri))
    фактический результат Sij = 1 при месте лучше, 0.5 при равном, 0 при хуже
    изменение Ri = 0.20 × среднее(Sij - Eij)

Сравнения относятся к итоговому порядку игроков, а не к личным матчам.
Результаты отдельных матчей и составы пар эта версия не учитывает.

Победитель при равных рейтингах получает +0.10.
Игрок 2.00, опередивший четырёх игроков 3.50, получает примерно +0.194.
Фаворит 3.50, проигравший четырём игрокам 2.00, теряет примерно 0.194.
Призовое место не гарантирует прибавку: результат должен превысить ожидание,
рассчитанное по силе состава. Пятое место само по себе не является порогом.

Расчёт хранит полную точность, интерфейс показывает два знака после точки.
Позиции таблицы определяются точным значением; отображаемые числа иногда совпадают.

## История и исправления

Турниры пересчитываются по дате начала, затем по ID при одинаковой дате.
Исправление старых мест заново рассчитывает и все более поздние турниры:
не добавляет новую награду поверх старой. До ввода итогов позднего турнира
его рейтинг неизвестен; при последующем вводе рейтинг будет пересчитан.
История изменений сохраняет рейтинг до турнира, после и разницу.

## Где смотреть

- /rating в подключённой группе или в личном чате бота.
- «Рейтинг группы» в главном меню: общий список и фильтры по буквенным уровням.
- «Мой профиль» и карточка участника в админке.
- Итоги завершённого турнира показывают рейтинг после этого турнира и изменение.
- После обновления повторный /bind обновляет закреплённое сообщение с кнопкой рейтинга.

Результаты, участники и рейтинги зависят от сохранности базы SQLite.
